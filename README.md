# Motec Network Camera Configurator (NCC)

The Repository contains the latest piblic release of the Motec **Network Camera Configurator (NCC)** for managing and configuring supported cameras and devices.  
With an intuitive user interface, the NCC makes cameras simple to set up, monitor, and optimize your network.  

## Supported Devices
The NCC is compatible with the following Motec camera models:
- **MCDx7000A**  
- **MCDx9000**  
- **MCDx3000**  
- **MCDx3000A**

## Features
- Easy-to-use graphical interface for camera configuration  
- Network discovery of supported devices  
- Quick setup for multiple cameras  
- Secure and reliable configuration process  
- Optimized for Motec’s industrial-grade camera systems  

## Getting Started
To get started with the NCC:
1. Download and install the latest release of the **NCC**.  
2. Connect your Motec device(s) to the network.  
3. Launch NCC and use the discovery tool to find your devices.  
4. Configure camera settings such as IP address, resolution, and streaming options.  

For a step-by-step introduction, please see our **video tutorials on YouTube**:  
 [Getting Started with NCC](https://www.youtube.com/watch?v=7PSNCV5NvOI)
